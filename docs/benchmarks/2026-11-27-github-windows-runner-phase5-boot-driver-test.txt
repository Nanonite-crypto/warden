Windows runner on 2026-11-27 about a driver that Windows loads while it
starts: a driver with the start "boot". The quarantine leaves the file of
such a driver where it is, and these are the facts about Windows which
that rests on.

The test is a_driver_that_windows_loads_while_it_starts_is_known_and_goes_
and_comes_back in crates/warden-autostart/tests/on_windows.rs. It passed.
In order, it prints:

  1. What `sc create` says to a driver whose file is in a temporary
     folder, with the start "boot" and with the start "demand".
  2. What `sc qc`, `sc sdshow` and `reg query` show of the test's driver,
     whose file is in the drivers folder of Windows.
  3. The file's path, and the ways Windows writes it.
  4. How many drivers with the start "boot" the look found, the test's
     own among them, and which of them the file belongs to.
  5. What starts the file, with the command lines Warden read, and the
     entry as Warden writes it down.
  6. What Windows' tools show after Warden has removed the entry and put
     it back.
